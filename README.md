# Technical Communications Portfolio

A simple static portfolio site. Edit `index.html` to update project titles and descriptions. Add your PDFs to the `projects` folder using the filenames `project-one.pdf`, `project-two.pdf`, and `project-three.pdf`, or change the links in `index.html` to match your files.

To publish: upload the contents of this folder to your GitHub repository. DigitalOcean App Platform can deploy the repository as a Static Site, with output directory `/` and no build command.
